# Portfolio (Next.js)

    npm install
    npm run dev

Edit `src/content/site.ts` first (full name, email, profile links, `NEXT_PUBLIC_SITE_URL`). Publications live in `src/content/publications.ts`; review the one-line takeaways. Media: photos in `src/assets` (auto blur placeholders, AVIF/WebP via next/image), video in `public/media` (lazy-loaded, loops, muted).
